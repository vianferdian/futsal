# Futsal Scoring System

Sistem Informasi Penilaian Pertandingan Futsal berbasis Laravel.

## Fitur Utama
- **Dashboard Administrator**: Kelola data master (Kompetisi, Tim, Pemain, Official, Venue).
- **Dashboard Pengawas**: Catat jalannya pertandingan secara real-time (Gol, Pelanggaran/Foul, Kartu, dll.).
- **Dashboard Admin Tim**: Kelola pendaftaran skuad & verifikasi susunan pemain (lineup).
- **Match Summary & PDF Report**: Unduh laporan ringkasan hasil pertandingan dalam format PDF yang rapi.
- **Responsive & Premium UI**: Tampilan visual yang menawan dengan notifikasi SweetAlert2.
